# 테스트와 검증 범위

정리 기준일: 2026-11-04. 이 문서는 기존 실행 기록과 현재 테스트 소스를 기준으로 확인된 범위와 추가 확인할 항목을 구분한다. 아래 체크리스트는 모든 항목이 실사용 검증을 끝냈다는 뜻이 아니다.

## 현재 검증 기록

2026-11-03의 `0.1.3 (build 4)` 배포 준비에서 전체 자동 테스트 **91개 통과(앱 67개·코어 24개)**를 다시 확인했다. 아래 실사용 확인 범위와 자동 테스트 결과는 구분한다.

2026-11-04의 커서 안정화 수정에서는 전체 **105개 통과(앱 81개·코어 24개)**를 확인했다. 빠른·정확한 Vision OCR에 세로줄·밑줄·블록 커서를 번갈아 그린 이미지와 숫자 수정·삭제를 넣었고, 누락·오인식 주입 및 번역 조각 픽셀 비교도 함께 검증했다. 외부 앱에서의 모든 커서 형태·실시간 입력 체감까지 확인했다는 뜻은 아니다.

같은 날 결과 창의 임시 선택 분리 후 전체 **110개 통과(앱 86개·코어 24개)**를 확인했다. 텍스트 읽기·인식/목표 언어의 저장 기본값 불변, 최신 기본값 복귀, 인식 해제 초기화, 일시정지·선택 상태 보존과 실제 번역 작업의 언어 적용을 자동 검증했다.

실제 앱에서는 결과 창의 `화면 OCR · 영어 → 일본어` 임시 선택 후 설정 창의 `자동 · 자동 감지 → 한국어` 기본값 유지를 확인했다. 두 팝오버의 ‘설정 기본값 사용’으로 복귀하고, 언어 복귀가 읽기 방식의 임시 선택에 영향을 주지 않는 것도 확인했다. 검증 후 임시 선택은 기본값으로 복구했다.

| 영역 | 확인된 근거 | 추가 확인 |
| --- | --- | --- |
| 창·영역 선택 | 실제 직접 클릭·겹친 창·창 내부 드래그·취소·목록 전환, 강조 영역 클릭 확정의 픽셀 회귀 테스트 | 외부 디스플레이·전체 화면·Spaces의 전체 조합 |

| 가림·비활성 창 | 주입한 창 목록으로 비활성 창·실제 겹침·최소화·닫힘·선택 범위·자체 오버레이 제외 자동 테스트 | 실제 앱 간 포커스 전환·팝업·창 이동 |
| 유휴 상태 | 해제 뒤 타이머 콜백 중단, 중복 방지, 일시정지·선택·수동 모드의 작업 정책 자동 테스트 | 안정화 이후 실제 CPU·에너지 영향의 장시간 비교 |
| 자동 실행·권한·아이콘 | 실제 로그인 항목 켜기→끄기→켜기, 같은 서명 재빌드 후 유지, 허용 상태와 아이콘 표시 확인 | 실제 다음 로그인·재부팅, 다른 경로 복사본 전환 |
| 서명·업데이트 | 통합 빌드·고정 서명·ZIP/피드 서명 및 변조 거부, 같은 Mac의 승인 유지, 임시 로컬 피드 설치·재실행 | 공개 HTTPS 배포·다른 Mac·Intel 하드웨어 |

기존 UI 자동화의 앱별 캡처는 투명 오버레이만 보여 주거나 도구의 가림 창·포커스 변경에 영향을 받았다. 실제 화면의 연속 표시·입력 체감과 자동 레이어 테스트 결과를 구분한다. 로컬 피드 검증의 임시 버전은 실제 배포 버전으로 해석하지 않는다.

## 자동 테스트 실행

```sh
swift test
# xcode-select가 Command Line Tools인 경우
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer xcrun swift test
```

- `Tests/LineLensCoreTests`: 좌표 변환, 문단 구성, 변경 영역, 문구 재사용, 프레임 버전, 스크롤 종료 상태.
- `Tests/LineLensTests`: 실제 OCR·설치 모델 번역, 이미지/레이어, 설정 마이그레이션, 언어 매핑, 권한 상태, 창 선택·가림, 페이드 취소, 유휴 타이머와 로그인 항목 서비스.
- 설치 언어 모델을 사용하는 테스트는 모델이 없거나 OS API가 맞지 않으면 건너뛰며 테스트가 모델을 임의로 다운로드하지 않는다. 로그인 항목 서비스 테스트는 주입한 등록·상태 함수로 수행한다.

앱 실행·서명 검증은 [설치·권한 문서](screen-permission.md), 배포 검증은 [Sparkle 문서](sparkle-updates.md)를 따른다.

## 검증용 창

`scripts/qa-fixture.swift`를 검증 앱으로 컴파일해 사용한다. 기본 창의 ‘Change last digit’와 ‘Change background mark’로 실제 글자 변경과 배경만의 변경을 구분한다.

- `--two-windows`: 일반·보조 창으로 앞쪽 창 선택, 일부 영역과 선택 취소를 확인한다.
- `--scroll` 또는 번들의 `LineLensScrollFixture = true`: 고정 헤더·사이드바와 NSScrollView 본문을 제공한다. ‘Jump down’은 500pt 이동한다.
- ‘Start smooth scroll’은 30fps·프레임당 3pt 자동 왕복, ‘Stop smooth scroll’은 중지다. 앱 내부 이동이므로 실제 휠 이벤트 기반 페이드 검증을 대신하지 않는다.

검증 후 자동 스크롤을 중지하고 검증 창·인스턴스를 정리한다. 배포 앱에는 이 스크립트를 포함하지 않는다.

## 수동 회귀 체크리스트

### 실행·권한·로그인 항목

- 최초 실행과 미승인 상태에서 안내가 표시되는가. 설정 → 권한의 실제 화면 기록·접근성 상태와 시스템 설정 연결이 맞는가.
- 접근성이 없어도 OCR을 사용하며 시스템 오디오를 녹음하지 않는가. 언어 모델 다운로드 안내와 오류도 원문 확인을 막지 않는가.
- 정상 업데이트 때 권한을 초기화하지 않는가. 복구가 필요한 경우 LineLens의 ScreenCapture만 초기화하고 재실행 후 승인하는가.
- 자동 실행 켜기·끄기·승인 대기·등록 실패·시스템 설정의 외부 변경이 실제 상태와 일치하는가. 다음 로그인에 메뉴 막대로 실행되는가.
- 앱 아이콘이 정보 창·번들에서 맞고, 재빌드 후 로그인 항목과 권한이 유지되는가.

### 영역·창 선택

- 기본 `Control + Option + L`, 직접 창 선택, 목록 검색·선택, 창 내부 영역과 영역 이동·크기 변경이 동작하는가.
- 강조가 그려진 뒤 클릭해도 바로 확정되고, 선택 클릭이 원래 앱의 버튼을 실행하지 않는가. 빈 바탕화면은 임의의 창으로 선택하지 않는가.
- 선택 취소·목록 닫기·직접 선택↔목록 전환 뒤 기존 대상이 복원되는가. Escape를 가로채지 않는가.
- 창 이동·크기 변경·최소화·닫힘·복귀, Retina·음수 모니터 좌표와 다른 Space에서 표시 위치가 맞는가. 고정 영역 드래그는 한 모니터 안에서 확인한다.

### 인식·언어·번역

- 앱 텍스트 우선과 화면 OCR 전환, 빠른/정확한 OCR 전환, 지정 언어 미지원과 낮은 신뢰도의 정확 모드 재시도가 동작하는가.
- 배경만 바뀌면 문단·번역·갱신 시각을 유지하고, 숫자 하나·문구 삭제·큰 화면 전환에는 필요한 영역을 갱신하는가.
- 짧은 문구의 자동 언어 식별 실패는 원문 언어 지정으로 재시도할 수 있는가. 혼합 문자와 AX 상자가 부정확한 앱도 확인한다.
- 결과 창에서 텍스트 읽기·인식 언어·목표 언어를 임시 선택하고 인식 언어 변경이 OCR·원문 언어에 함께 적용되는가. 실제 선택 후에도 설정 창의 저장 기본값은 바뀌지 않는가.
- ‘설정 기본값 사용’이 최신 설정을 따르는가. 언어 복귀가 읽기 방식의 임시 선택을 지우지 않고, 일시정지·스크롤은 선택을 유지하며 인식 해제·앱 재실행은 초기화하는가.
- 중국어 간체/번체·지역 코드 매핑, 새 OCR 전 이전 언어의 잘못된 재번역 방지, 품질별 캐시와 모델 지원이 맞는가.
- 번역 끄기, 원문 수정·재번역·복사, 결과 창 고정·최소 폭, 설정·해제한 단축키의 재실행 후 보존이 동작하는가.

### 일반 표시·클릭·가림

- 밝고 어두운 UI에서 번역 글자와 아이콘·버튼·구분선이 맞고, 최소 글자 크기에서도 넘치는 번역은 영역 안에서 제한되는가.
- 클릭·드래그·키보드 입력이 원래 앱에 전달되는가. 배경과 클릭 결과가 번역을 기다리며 멈추지 않는가.
- 일반 갱신의 새 레이아웃·‘…’·부분 번역 표시와, 진행 중인 번역을 반복 취소하지 않는 동작을 확인한다.
- 실시간 표시 끄기는 일반 갱신에서 이전 완성 화면을 유지하는가. 자동 갱신 끄기는 수동 새로고침 전까지 마지막 화면을 유지하는가.
- 다른 앱으로 포커스를 옮겨도 대상 영역을 가리지 않으면 유지하는가. 실제 겹침·최소화·닫힘은 숨기고, 가림을 치우면 다시 표시하는가.
- 별도 title 툴팁도 현재는 전체 숨김 조건임을 확인한다. 창 내부 범위 밖의 겹침·뒤쪽 창·번역 오버레이 자체는 가림으로 세지 않는가.
- 비활성 창을 가린 다른 앱의 클릭·스크롤을 대상 입력으로 오인하지 않는가. 보이는 비활성 창의 직접 스크롤은 별도로 확인한다.

### 스크롤·페이드

- 자동 번역·자동 갱신·번역 오버레이에서 시작 즉시 약 80ms 페이드아웃하고 원문이 보이는가. 이전 번역·좌표·이미지 캐시가 폐기되는가.
- 스크롤 중 주기적/수동 갱신·이전 응답이 번역이나 ‘…’를 되살리지 않는가. 손을 뗀 뒤 관성이 끝날 때까지 원문을 유지하는가.
- 종료 뒤 최신 화면으로 새 인식을 수행하고, 번역이 준비되면 현재 좌표에 약 100ms 페이드인하는가. 기존 번역문 캐시는 새 문단 ID에 적용되는가.
- 같은 크기의 투명 창과 opacity만 사용하며 확대·축소·이전 배경·불투명한 중간 프레임이 번쩍 보이지 않는가.
- 재스크롤·빠른 방향 반전·페이지 점프·화면 끝의 무변화·팝업·대상 변경·일시정지 시 늦은 작업이 잘못 복원되지 않는가.
- 작은 로딩 표시·동영상이 복귀를 무한히 지연시키지 않는가. 실시간 표시를 꺼도 자동 갱신의 스크롤 전환은 적용되는가.
- 키보드·스크롤바·앱 내부 이동은 기존 인식 경로이며 휠 이벤트 기반 페이드를 보장하지 않는다는 범위를 확인한다.

### 유휴 상태·재개

- 대상 없음·인식 해제·일시정지에서 캡처·인식·번역과 갱신/오버레이 타이머·입력 감시가 중단되는가. 늦은 프레임·페이드·종료 타이머도 남지 않는가.
- 다른 앱의 마우스·스크롤로 작업이 다시 시작되지 않는가. 단축키·메뉴로 인식 재개는 가능한가.
- 재개·설정 변경·선택 취소 후 필요한 작업만 시작되고 중복되지 않는가. 자동 갱신을 꺼도 오버레이 유지에는 창 위치·가림 확인이 필요함을 구분한다.
- 초기 작업과 캡처 종료가 안정화된 뒤 실제 CPU·에너지 영향을 비교한다. 단축키·기본 UI·업데이트 확인까지 포함해 항상 수치 0이라고 가정하지 않는다.

### 배포·업데이트

- 버전·빌드 번호 증가, 통합 실행 파일, 고정 서명·이전 앱의 DR, ZIP·피드 서명이 맞는가. 잘못된 키·변조 파일·기존 버전 덮어쓰기는 거부되는가.
- 비로그인 HTTPS에서 피드와 ZIP을 받을 수 있고, 이전 Sparkle 포함 앱에서 설치·재실행·화면 기록·설정 유지가 되는가.
- 새 Mac의 최초 실행 허용·권한 승인, Intel 하드웨어와 실제 로그아웃 후 자동 실행도 별도로 확인한다.
