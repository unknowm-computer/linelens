LineLens 설치 및 업데이트

macOS 15 이상에서 사용할 수 있습니다. Apple Silicon과 Intel Mac을 지원합니다.

처음 설치할 때
1. ZIP 파일을 압축 해제합니다.
2. LineLens.app을 응용 프로그램 폴더로 옮긴 뒤 실행합니다.
3. 메뉴 막대의 LineLens에서 화면 영역을 선택하거나 ‘프로그램 창 직접 선택’을
   누르고 화면에서 원하는 창을 클릭합니다. 창 내부 영역은 위쪽에서 선택한 뒤
   원하는 창을 클릭하고 이어서 영역을 드래그합니다.
4. 화면 기록 권한을 요청하면 시스템 설정의 개인정보 보호 및 보안 →
   화면 및 시스템 오디오 녹음에서 LineLens를 허용합니다.
   macOS에서 재실행을 안내하면 앱을 종료한 뒤 다시 실행합니다.

새 버전으로 업데이트할 때
LineLens 0.1.2 이상에서는 메뉴의 ‘업데이트 확인…’을 누르고 안내에 따라
설치·재실행합니다. 설정에서 ‘자동으로 업데이트 확인’을 켤 수도 있습니다.
업데이트 서버에 새 버전과 피드가 게시되어 있어야 합니다.

0.1.1 이하에서 처음 업데이트하거나 ZIP으로 직접 교체할 때
1. 메뉴 막대에서 LineLens를 종료합니다.
2. 새 ZIP 파일을 압축 해제합니다.
3. 새 LineLens.app을 응용 프로그램 폴더로 옮기고 기존 앱을 대치합니다.
4. 교체한 앱을 실행합니다.

업데이트 때 기존 화면 기록 항목을 삭제하거나 권한을 초기화할 필요는 없습니다.
앱의 기존 설정도 그대로 사용합니다.

앱 실행이 차단될 때
이 배포본은 Apple 공증을 받지 않은 자체 서명 앱입니다.
직접 받은 LineLens 배포본임을 확인한 경우 시스템 설정 → 개인정보 보호 및
보안에서 해당 앱의 실행 허용 안내를 확인하세요. 설치·업데이트 때 실행
허용이 필요할 수 있으며, 이것은 화면 기록 권한과 별도의 macOS 확인입니다.

개발 도구나 서명 키체인을 설치할 필요는 없습니다.
