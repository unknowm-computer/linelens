LineLens 0.1.5 (빌드 6)

OCR 번역 표시를 안정화하고 인식 결과 창의 설정을 더 편하게 조정할 수 있도록 했습니다.

- 커서가 깜빡일 때 기존 번역을 유지하면서 실제 텍스트 수정·삭제는 빠르게 반영합니다.
- 인식 결과 창에서 텍스트 읽기 방식을 바로 선택할 수 있습니다.
- 결과 창의 텍스트 읽기·인식 언어·목표 언어 선택은 현재 인식에만 적용하며 설정의 기본값을 바꾸지 않습니다.
- ‘설정 기본값 사용’으로 최신 기본값에 복귀할 수 있으며 인식을 해제하면 임시 선택도 초기화합니다.
- 배포 빌드의 디버그·로컬 심벌과 Sparkle 개발용 헤더·모듈을 정리해 앱 용량을 줄였습니다.

macOS 15 이상, Apple Silicon·Intel Mac을 지원합니다.
기존 코드 서명과 업데이트 서명을 유지했습니다.
