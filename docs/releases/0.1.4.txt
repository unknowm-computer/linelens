LineLens 0.1.4 (빌드 5)

사용하지 않을 때의 자원 사용을 줄였습니다.

- 결과 화면을 필요할 때 생성하고, 인식 대상이 없는 상태에서 창을 닫으면 숨은 화면 자원을 해제합니다.
- 설정·권한 안내·창 선택 화면을 닫을 때 화면 호스트와 구독을 정리합니다.
- OCR·번역 지원 언어 목록을 설정 또는 언어 팝오버를 열 때 조회하고 재사용합니다.
- 자동 업데이트 확인이 꺼져 있으면 수동으로 확인하거나 자동 확인을 켤 때 Sparkle를 초기화합니다.
- 인식 중에는 결과 창을 닫아도 화면 위 번역을 유지합니다.

macOS 15 이상, Apple Silicon·Intel Mac을 지원합니다.
기존 코드 서명과 업데이트 서명을 유지했습니다.
