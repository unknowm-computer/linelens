# 번역 오버레이 현재 구현

기준일: 2026-11-03. 현재 소스의 동작을 정리한 문서다. 초기 구상과 대체된 이동 추적 계획은 제거하고, 완료된 스크롤 전환 내용을 통합했다.

## 인식 대상과 처리 흐름

화면 영역·프로그램 창·창 내부 영역을 사용자가 해제할 때까지 유지한다. 프로그램 창은 위치와 크기를 추적하며 일반 창과 떠 있는 창을 선택할 수 있다. 직접 클릭 선택과 목록 선택을 제공하고 선택 취소는 기존 대상을 보존한다.

1. ScreenCaptureKit으로 현재 대상의 화면을 받는다. 자동 갱신 또는 오버레이 사용 중에는 캡처 세션을 유지한다.
2. ‘앱 텍스트 우선’에서는 허용된 접근성 정보로 현재 문구와 위치를 읽는다. 사용할 수 없으면 Vision OCR을 사용한다. 화면 영역 선택은 OCR을 사용한다.
3. 기존 문구의 번역을 재사용하고 새 문구를 Apple Translation으로 번역한다.
4. 주변 색·글자색을 추정해 작은 번역 이미지 조각을 생성하고, 원문 위치에 Core Animation 레이어로 표시한다. 전체 화면을 매번 CPU 이미지로 합성하지 않는다.

## 인식과 번역 설정

| 항목 | 현재 동작 |
| --- | --- |
| OCR 모드 | 빠름·정확 선택, 기본 빠름. 지원 언어는 실행 환경에서 조회 |
| 빠른 OCR 보완 | 지정 언어 미지원 또는 평균 신뢰도 0.3 미만이면 정확 모드 재시도. 결과가 비면 텍스트 검출 후 필요한 영역만 재시도 |
| 부분 OCR | 64px 변경 타일을 이전 문단 범위까지 확장. 영역이 8개를 넘거나 면적이 45%를 넘으면 전체 인식 |
| 앱 텍스트 | 보이는 AX value/title과 위치를 읽고 비밀번호 필드·화면 밖·중복 문구 제외. 창 식별 실패·텍스트 없음·큰 이미지/캔버스는 OCR 전환 |
| AX 탐색 제한 | 메시지별 60ms, 전체 약 450ms, 최대 1,500노드. 미지원 창은 5초 후 재시도 |
| 번역 속도·품질 | 기본 속도 우선. macOS 26.4 이상에서 lowLatency/highFidelity 선택, 이전 OS는 시스템 기본 번역 |
| 언어 선택 | 결과 창의 인식 언어는 OCR·번역 원문 언어를 함께 변경. 설정에서는 개별 선택 가능 |
| 번역문 캐시 | 원문 언어·목표 언어·품질·문구별로 구분, 최대 500개. 전체 캐시 적중이면 새 번역 세션 없이 즉시 반환 |

한국어·일본어 화면이나 혼합 문자에서 빠른 OCR이 일부 문자를 놓칠 수 있다. 언어 지정 또는 정확한 OCR을 사용한다. AX 텍스트 상자가 실제 글자보다 넓은 앱에서는 화면 OCR을 선택할 수 있다. 짧은 문구만으로 원문 언어를 자동 식별하면 실패할 수 있다.

## 일반 화면 갱신

실시간 화면 표시에서는 ScreenCaptureKit의 IOSurface를 배경 레이어에 전달한다. 캡처 간격은 최대 30fps를 요청하고, 이미지 변환·픽셀 분석은 최대 5fps로 합친다. 실제 속도나 지연을 보장하는 수치는 아니다.

배경 표시는 OCR·번역 완료를 기다리지 않는다. 일반 갱신에서는 새 레이아웃을 먼저 표시하며 번역 대기 문구를 ‘…’로 가리고, 부분 번역 결과를 약 100ms 간격으로 반영한다. 새 OCR 때문에 진행 중인 번역을 반복 취소하지 않고 다음 문구를 대기시킨다. 이미 목표 언어인 문구와 숫자·기호는 원문으로 확정한다.

실시간 표시를 끄면 일반 갱신에서 다음 인식·이미지 생성까지 이전 완성 화면을 유지한다. 자동 갱신을 끈 수동 모드는 마지막 번역 화면을 유지하며 명시적 새로고침으로 갱신한다. 스크롤 전환은 아래 별도 규칙을 따른다.

캡처·인식·렌더링의 버전을 관리하고 현재 글자와 맞지 않는 오래된 결과를 거부한다. 글자 밖 배경 애니메이션은 허용하며, 일시적 오류에는 이전 표시를 유지한다. 빈 화면의 인식이 완료되면 이전 번역 조각을 제거한다.

## 스크롤 중 원문 표시

자동 갱신과 번역이 켜진 오버레이에 적용한다. 이전의 이미지 이동량 계산·좌표 투영·번역 레이어 이동 추적은 제거했다.

1. 휠·트랙패드 스크롤 시작 시 번역을 약 80ms 동안 페이드아웃한다. 캡처 배경은 즉시 해제해 원래 앱을 보여 준다.
2. 이전 인식·번역을 취소하고 문단 ID·좌표, OCR 픽셀·문단 캐시, 번역 이미지·렌더러 캐시를 폐기한다. 번역문 텍스트 캐시와 지속 캡처는 유지한다.
3. 스크롤 중 새 OCR·번역과 수동·주기적 새로고침 요청을 보류한다. 다시 스크롤하면 준비 중인 결과도 폐기한다.
4. 손을 뗀 뒤 관성이 이어지는 구간을 포함해 종료를 판단한다. 최신 캡처로 전체 범위를 새로 인식하며, 픽셀이 바뀌지 않은 화면 끝에서도 다시 인식한다.
5. 새 화면의 번역이 모두 준비되면 현재 좌표에 이미지를 생성하고 약 100ms 동안 페이드인한다. 이전 이미지·좌표나 ‘…’를 먼저 복원하지 않는다.

| 종료 판단 | 현재 값 |
| --- | --- |
| 일반 휠·제스처 종료·관성 종료 후 무입력 | 약 240ms |
| 진행 중 단계의 종료 이벤트가 누락된 경우 | 약 400ms 무입력 후 판단 |
| 시각적 안정 확인 | 기존 픽셀의 32×24 밝기 샘플. 넓은 변화가 계속되면 약 220ms 더 대기 |
| 영상 등으로 인한 시각적 대기 상한 | 마지막 입력 후 최대 1초 |

시각적 안정 확인은 새 이미지 변환이나 이동량 계산을 하지 않는다. 이후에도 실제 글자가 바뀌면 기존 화면 일치 검증이 오래된 결과를 거부할 수 있다.

고정 헤더·사이드바를 포함한 번역 레이어 전체를 해제한다. 실시간 표시를 꺼도 자동 갱신의 스크롤에서는 이 전환을 사용한다. 키보드·스크롤바·앱 내부 자동 스크롤은 휠 이벤트 기반 페이드를 보장하지 않으며 기존 화면 변경 인식 경로를 따른다.

## 깜빡임·입력·표시 범위

오버레이 NSPanel은 `animationBehavior = .none`, `ignoresMouseEvents = true`를 사용한다. 클릭·스크롤·드래그는 아래 앱으로 통과한다. 전체 창 상단 32pt는 제목 표시줄과 시스템 녹화 표시를 위해 원래 화면을 유지한다.

스크롤 중에는 같은 크기의 투명 창을 유지하고 레이어 opacity만 바꾼다. 페이드가 끝나면 레이어를 비우며, 새 좌표·이미지·초기 opacity는 하나의 트랜잭션으로 반영한다. 실시간 복귀 배경에는 과거 OCR 이미지 대신 최신 캡처 버퍼를 사용한다.

프로그램 창의 활성 여부는 표시 조건으로 사용하지 않는다. 비활성 창도 대상 영역이 보이면 유지하며, 다른 창이 실제로 겹치거나 최소화·닫힘·다른 Space 등으로 화면에 없으면 숨긴다. 현재는 부분 겹침에도 전체 오버레이를 숨긴다. 창 내부 영역 선택은 선택 범위의 가림만 판단한다.

별도 툴팁·팝업도 실제 겹침에 해당한다. 팝업 구분·겹친 부분만 제외·팝업 별도 번역은 미구현이며 [후속 계획](popup-translation-overlay.md)에 정리한다. 페이지 안의 HTML/CSS 팝업은 같은 창 캡처에 포함되는 경우 기존 인식 경로를 따른다.

## 유휴 상태와 재개

인식 대상 없음·인식 해제·일시정지·대상 선택 중에는 인식 갱신 타이머, 100ms 오버레이 확인 타이머와 전역/로컬 마우스 감시를 해제한다. 캡처·인식·번역, 스크롤 종료 대기·페이드·지연 새로고침을 취소하고 늦은 프레임도 처리하지 않는다.

대상 선택·재개·설정 변경 시 필요한 작업만 다시 시작하며 중복 등록을 막는다. 자동 갱신을 끈 상태에서도 오버레이를 유지하면 창 위치·가림 확인은 계속한다. ‘자동 번역’만 끈 경우 자동 OCR은 유지할 수 있다. 단축키 대기는 이벤트 방식으로 유지하며 기본 UI·업데이트 확인까지 포함한 앱 소비량이 항상 수치 0이라는 뜻은 아니다.

## 제약과 검증

배경 복원은 줄별 주변 색 추정이며 사진·무늬의 인페인팅과 원본 폰트 복원은 포함하지 않는다. 번역문은 원래 영역 안에서 줄바꿈·축소하며 최소 9pt에서도 넘치면 생략할 수 있다. AX 위치, 혼합 문자·세로쓰기·다단 문서와 앱별 팝업 구성에도 제약이 있다.

기능별 자동·수동 검증 근거와 미검증 범위는 [테스트 문서](manual-testing.md)를 기준으로 한다. 테스트 이미지의 처리 시간이나 캡처 요청 주기를 전체 실사용 지연으로 해석하지 않는다.
