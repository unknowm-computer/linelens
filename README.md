# LineLens

화면 영역이나 프로그램 창의 글자를 인식하고 번역하는 macOS 메뉴 막대 앱이다. 캡처는 ScreenCaptureKit, OCR은 Vision, 번역은 Apple Translation을 사용한다. OCR·번역은 기기에서 처리하며 별도 LLM·번역 API 키·외부 번역 서버는 사용하지 않는다. 언어 모델의 최초 다운로드와 업데이트 확인에는 인터넷이 필요하다.

## 시작하기

macOS 15 이상을 지원한다. 설치받는 사용자는 `LineLens.app`을 응용 프로그램 폴더처럼 유지할 위치에 설치하고 화면 기록 권한을 허용한다. 상세 절차는 [설치 안내](docs/distribution-install.txt)와 [설치·권한·서명 문서](docs/screen-permission.md)를 참고한다.

1. 메뉴 막대에서 ‘화면 영역 선택’ 또는 ‘프로그램 창 직접 선택’을 실행한다. 결과 창의 ‘창 선택’도 직접 선택을 시작한다.
2. 창 선택에서는 ‘전체 창’ 또는 ‘창 내부 영역’을 고른다. 목록 선택으로 전환할 수도 있다. 화면 위 ‘취소’와 메뉴의 ‘선택 취소’는 기존 대상을 유지한다.
3. 결과 창의 ‘언어’에서 인식 언어와 목표 언어를 선택한다. 인식 언어는 OCR 언어와 번역 원문 언어에 함께 적용된다. 설정에서는 두 언어를 개별 지정할 수 있다.
4. 번역 화면은 클릭·스크롤을 아래 앱으로 통과시킨다. 결과 창에서는 원문 수정·재번역·복사와 창 고정을 사용할 수 있다.
5. ‘일시정지’는 대상을 보존하고 작업을 멈춘다. ‘인식 해제’는 대상을 해제한다. 다시 선택하거나 재개하면 필요한 감시가 시작된다.

영역 선택 기본 단축키는 `Control + Option + L`이다. 인식 해제 단축키는 기본 미지정이며 설정에서 변경할 수 있다. Escape는 전역 취소·해제로 가로채지 않는다.

## 현재 기본 설정

| 항목 | 새 설정의 기본값 |
| --- | --- |
| 텍스트 읽기 | 자동 · 앱 텍스트 우선 |
| OCR 모드 | 빠른 OCR |
| 인식 언어 | 자동 감지 |
| 목표 언어 | 한국어 |
| 자동 번역·자동 갱신 | 켜기·2초 |
| 번역 처리 | 속도 우선 |
| 결과 표시 | 번역 화면 · 이미지 속 글자 바꾸기 |
| 실시간 화면 표시 | 켜기 |

기존에 저장한 언어·단축키·표시 설정은 유지한다. 번역 속도·품질 선택은 macOS 26.4 이상에서 지원하며 이전 OS에서는 시스템 기본 번역을 사용한다. 빠른 OCR의 지원 언어는 실행 환경에 따라 제한되므로 한국어·일본어 등은 언어를 지정하거나 정확한 OCR을 선택한다.

## 표시와 갱신

- 프로그램 창은 비활성이어도 화면에 보이고 번역 영역이 가려지지 않으면 번역을 유지한다. 다른 창·메뉴·별도 툴팁이 실제로 겹치거나 대상이 최소화·닫힘 상태면 숨긴다. 일부만 겹쳐도 현재는 오버레이 전체를 숨긴다.
- 자동 갱신의 번역 오버레이는 휠·트랙패드 스크롤을 감지하면 번역을 약 80ms 동안 페이드아웃한다. 이전 번역 이미지·좌표·OCR 캐시는 폐기하고 새 인식·번역 요청을 보류한다.
- 관성까지 멈추면 현재 화면을 새로 인식한다. 번역문 텍스트 캐시만 재사용하고, 새 번역이 준비되면 현재 위치에 약 100ms 동안 페이드인한다. 같은 크기의 투명 창을 유지하며 opacity만 변경한다.
- 실시간 표시를 끈 경우에도 자동 갱신 중의 스크롤은 위 전환을 사용한다. 그 외 일반 갱신에서는 이전 완성 화면을 유지한다. 자동 갱신을 끈 수동 모드는 마지막 화면을 유지하며 수동 새로고침으로 갱신한다.
- 인식 대상 없음·인식 해제·일시정지·대상 선택 중에는 인식용 갱신/창 추적 타이머와 마우스·스크롤 감시를 중단한다. 인식 시작용 단축키는 이벤트 방식으로 대기한다. ‘자동 번역’만 끄고 인식을 유지하면 OCR은 계속 동작할 수 있다.

캡처·부분 인식·캐시·스크롤 시간값과 제약은 [번역 오버레이 구현 문서](docs/translated-image-overlay.md)에 정리한다.

## 설정·권한

- 화면 기록은 캡처·OCR에 필요하다. 접근성은 앱 텍스트 직접 읽기용 선택 권한이며 미허용 시 OCR을 사용한다.
- 설정의 ‘로그인 시 자동 실행’은 macOS 로그인 항목 상태와 연동한다. 앱을 실행할 때마다 강제로 등록하지 않는다.
- 권한 조회·복구, 자동 실행, 아이콘 생성과 빌드 신원은 [설치·권한·서명 문서](docs/screen-permission.md)를 참고한다.
- 업데이트 확인 메뉴와 설정을 제공한다. 자동 업데이트 확인은 기본 끄기이며 게시된 피드가 있어야 동작한다. [배포·업데이트 문서](docs/sparkle-updates.md)를 참고한다.

## 소스 빌드와 테스트

Swift 6 및 macOS 프레임워크를 포함하는 Xcode 개발 환경이 필요하다. `Package.swift`를 열 수 있으며 업데이트 의존성은 Sparkle 2.10.1로 고정한다. 최초 패키지 다운로드에는 인터넷이 필요하다.

다음은 기존 고정 서명 키를 보유한 개발 Mac의 절차다. 설치받는 사용자나 개인 키가 없는 다른 Mac에서 새 인증서를 만들어 대체하지 않는다.

```sh
./scripts/setup-local-signing.sh
./scripts/build-app.sh release
open dist/LineLens.app
swift test
```

`xcode-select`가 Command Line Tools를 가리키면 다음과 같이 Xcode를 지정한다.

```sh
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer ./scripts/build-app.sh release
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer xcrun swift test
```

빌드는 별도 디렉터리에서 조립·서명·검증한 후 앱을 교체한다. 같은 결과물이면 기존 앱을 보존한다. 고정 서명이 없거나 일치하지 않으면 중단하며 임시 서명으로 자동 전환하지 않는다. 배포용 통합 앱과 서명된 업데이트 생성은 [Sparkle 문서](docs/sparkle-updates.md)를 따른다.

## 제약과 후속 작업

사진·무늬 배경은 글자 주변의 단색으로 덮는다. 인페인팅·원본 폰트 복원은 포함하지 않으며 긴 번역은 원래 영역 안에서 축소·생략될 수 있다. 짧은 문구의 자동 언어 식별, 혼합 문자와 복잡한 배치에는 제한이 있다.

별도 툴팁·시스템 팝업을 구분해 해당 영역만 제외하거나 팝업을 따로 번역하는 기능은 미구현이다. 현재는 실제 겹침 시 전체를 숨긴다. [팝업 처리 계획](docs/popup-translation-overlay.md)에 후속 작업을 정리한다.
